## REMOVED Requirements

### Requirement: Explicit source-bound atlas

**Reason**: A particular ETHOS page set is source/editor-owned content, not a
generic Publisher capability or a required legacy HTML reproduction mode.

**Migration**: Select complete question-scoped views through `edition-publication`
and independently compose their media through `semantic-publication`. Preserve
exact source and visual-refinement identities and designated acceptance.

### Requirement: Non-overwriting atlas output

**Reason**: Complete Candidate emission and exact authorized installation already
have generic owners; a source-named output contract duplicates them.

**Migration**: Use `edition-publication` for complete build output and
`file-publication` for selected destination preservation and recovery. Retain
failed partial output and refuse a successful complete result after drift.

### Requirement: Explicit semantic candidate

**Reason**: Candidate, qualification and publication are generic distinct values.
An ETHOS-specific candidate contract is not an additional semantic authority.

**Migration**: Use the generic Edition Candidate and qualification contracts.
Bind exact inputs and media; new semantic or visual bytes require their own
applicable qualification and designated acceptance, not inherited approval.

### Requirement: Checked authored semantic edits

**Reason**: Repository-specific edit sites and semantic replacements belong to
the source/editor, not to a Publisher-owned ETHOS patch grammar.

**Migration**: Supply source-owned native inputs and an attributed Edition with
selected visual refinement. Generic compilation retains exact references,
visible coverage and qualification without inferring prose equivalence or
source acceptance.
