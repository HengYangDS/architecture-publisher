# Reader and intrinsic composition design

## Reader mechanism

Complete figures and page navigation remain independently usable. Native reading
uses the declared model or view, not guessed drawing/source equivalence. The
supplied reader owns layout stability and interaction state; navigation,
provenance, Inspect and parent/member mapping must earn candidate acceptance.
Prefer supported native equivalents and retain only demonstrated gaps, never
duplicate camera, layout or search owners. Capabilities require the renderer's
artifact-bound contract, not a JavaScript string in HTML. Unsupported outcomes
remain open.

Native finite Route journeys remain native-owned when offered. Manual figures,
navigation and Inspect require no playback. Add no chapter/query controller,
timer, load-time autoplay or ambient-motion promise.

### Product review of PR 795

The maintainer prioritizes request, typed specification, then native rendering
with relationship data. An incomplete custom SVG would extend several Viewer
features and impose ongoing maintenance. A concrete workflow must demonstrate
why supported typed generation is insufficient before renewed scope agreement.
Green retained-head CI resolves failing checks, not demand or maintainer
acceptance; implementation, rebasing and integration stay paused.

Publisher's self-Edition combines entities and internal relations into explanatory
figures. `sourceExploration()` drops all query relations when any mapping is
non-bijective, despite known source facts. `applyTemplate()` assembles SVG, cards
and locale data; it supplies no model/view or custom source-query contract.
Repair this projection mismatch rather than requiring an unsupported Viewer mode.

Source owns exact identities, kinds, endpoints, assertions and qualifications;
views select scope and bind occurrences to source members; composition owns paint.
View-only groups are not source entities. Collapsing `b1` and `b2` can create
visual `A -> B -> C` from `a -> b1` and `b2 -> c` without a source path. Repeated
occurrences can hide real paths; shared strokes must retain distinct relation
identities and endpoints. Source queries use source endpoints; collapsed edges
expose their contributing relations. Paths prove neither causality nor execution.

Select capabilities and pages for distinct questions, not every control on
every page. Prefer native detail/expansion or an exact view with subject,
provenance and return preserved. Omitting queries, reporting zero or lowering
quality cannot close an unsupported outcome.

| Alternative                     | Disposition                                                                                                                       |
| ------------------------------- | --------------------------------------------------------------------------------------------------------------------------------- |
| Use a mature framework directly | Prefer it when supported configuration passes the same complete publication journey; remove redundant Publisher responsibilities. |
| Use official typed Archify      | First low-migration comparison; preserve exact source types separately from its component roles.                                  |
| Use a model/view-native product | First replacement candidate after a faithful typed journey fails; LikeC4 must prove reading, independent media and artwork.       |
| Retain Publisher                | Keep only demonstrated source-bound assertion, editorial, independent-media, qualification and publication responsibilities.      |
| Extend an official seam         | Only after smaller supported alternatives fail a concrete requirement and the maintainer accepts the generic scope.               |
| Depend permanently on PR 795    | Reject; honest refusal does not repair the model/view mismatch.                                                                   |

A narrow publication boundary is not proof that Publisher is necessary. Direct
mature-tool use and existing source/custody owners are its falsifiers. Use one
source model, public input journey, Inspect authority and quality contract; reuse
native parser, layout and reading through one internal renderer adapter. Raw
native-mode rendering refuses declared incomplete exploration before output;
the public build preserves the figure and provides checked source reading. Do not
create another canonical graph or require ETHOS/AIGW runtime code, directories
or repository-specific contracts. External authored inputs and an optional
supported Provider remain the boundary. Backend replacement creates neither
adopter machinery nor quality tiers. PNG6000 remains independently composed.

Archify's component vocabulary is not its diagram-type ceiling. Workflow,
sequence and dataflow reuse roles; lifecycle has state kinds. Keep exact source
types and reader meaning: a Claim is not a backend and a chain is not execution.
Respect the maintainer pause; independent reviews justify no second reader or
compulsory Publisher layer.

Qualify the hardest self-Edition aggregate/literal view with unchanged claims,
repeats, shared traversals, source-path counterexamples, keyboard/pointer return,
intrinsic layout, styles/accessibility, offline standalone HTML, installed replay
and independent PNG6000. Reject patches, duplicate controllers, source changes,
coercion, lost members or worse reading; a site/API/parser pass cannot qualify it.

#### Selected declarations in original Archify

One checked source projection binds each selected entity, relationship and
Claim to its exact namespace, class and identity. Complete imports remain
private. Required ancestors retain identity and hierarchy without disclosing
unselected names or records. Relationships retain source endpoints, kinds,
direction and provenance; drawing groups and shared strokes never create
additional source facts. Editorial assertions remain explicitly attributed to
their Edition rather than promoted to source Claims.

The same original Archify reader renders the selected declarations. Its native
Finder, Passport, Route, Reach and Lens own query and interaction state; there is
no private query engine, alternate graphical runtime or layout Worker. Source
references bind the native carriers back to the checked projection. Native
traversals over a bidirectional relationship retain its canonical predicate;
a reverse traversal does not create another source assertion.

| Reader question                                      | Required result                                                 |
| ---------------------------------------------------- | --------------------------------------------------------------- |
| Which selected entities have this exact source type? | Exact kind membership, not substring or visual-role matching    |
| Does a directed connection link these two subjects?  | A source-relationship path, not successive occurrence clicks    |
| What can be reached from this subject?               | Outgoing transitive reach, not an execution or causality claim  |
| What reaches or depends on this subject?             | Incoming transitive reach over selected relationship directions |

Queries use the current page's checked published declarations, never arbitrary
repository content or unselected imports. Source identity, explanatory occurrence
and current reader state remain distinct. Complete source records stay available
in Inspect; concise labels cannot silently remove qualifications. Unsupported
native behavior remains an explicit qualification gap, not a zero-result claim.

Task 2.3 requires public-build, installed, offline and native-platform evidence;
Task 2.6 retains exact-record and Inspect acceptance. Passing source projection
or supply checks does not establish browser interaction, artwork or full parity.

### Inspect organization

Inspect is a reading projection, not another graph or an acceptance authority.
Its record classes come only from the validated reference tuple: Entity,
Relationship, Claim and Editorial statement. Present them in that order and
keep editorial attribution visibly separate from source declarations. Names,
titles and repository-specific qualifier keys never determine a record class.

Keep the selected graphic and page as context. Present the already authored
native sublabel, tag and context as exact diagram text, not an inferred source
summary. Never promote a qualifier key or the first source member into the
graphic's explanation. The object title identifies the selected graphic; an
explicit Diagram text heading distinguishes its display wording from typed
source declarations. Section headings follow that object title without
skipping a document level. Group exact records by their declared class. A singleton
section opens directly; a multi-record section starts as a symmetric outline
and never promotes its first record through input order. Native disclosures
retain every record and exact field. The index identifies available classes
rather than making record counts its primary explanation. Native Archify
Passport, Finder, Route, Reach and Lens still own graph exploration.

The reading surface is one document, not a stack of independently sized cards.
Record headings, field labels and values share intrinsic columns through native
CSS subgrid. Fine rules divide records; borders do not surround each record.
This private presentation change does not introduce field-role tags, parse
human labels into semantics, factor unequal attribution or expand public input.
Source identity uses the same document rules, not another framed card.
Exact provenance remains attached to each declaration until its existing
typed owner can support safe factoring; source identity stays separately
available. Sparse subjects retain readable content measure rather than fake
content, oversized cards or an empty decorative column.

Inspect uses one compact page frame rather than repeating the selected title
above both panes. Search and the selected occurrence heading occupy the same
control row; their lists share the next row's top and bottom bounds. The selected
occurrence remains explicit even while another directory row is hovered or the
reader scrolls elsewhere. Hover never copies the current-selection appearance.
Opening an occurrence brings its directory entry into view without moving the
reader to an unrelated entry or altering source identity.

Present canonical JSON object or array values through a collapsed native
disclosure, without interpreting domain keys or changing scalar types. Expanded
values use nested key/value data and retain each original value verbatim in its
own disclosure. Plain fields remain readable by default. Noncanonical or
structurally large values remain exact text instead of being guessed, truncated
or silently discarded. Source and Edition input identities remain separately
inspectable; their presence confers neither semantic endorsement nor publication
approval. Container type belongs to its disclosure; it is not repeated as a
standalone paragraph at every nesting level.

Inspect owns its typography. Top-level fields use one bounded label column;
nested fields use a smaller consistent column and a predictable indentation.
Values receive the remaining readable width. Record heights follow complete
content rather than equal-height clipping. Source data requires no formatting
annotations, and expansion preserves exact values and typed hierarchy.

### Intrinsic composition

Typesetting belongs inside the publishing implementation, not upstream; prefer native mechanisms.
Retain Publisher code only for a proved gap. Sources and editors provide exact content,
relationships, declared groups and expressive priorities. The scene admits an automatic form
without a viewport, node positions or sizes, edge ports or points, or text
coordinates. Complete supplied geometry is the explicit literal alternative;
partial mixtures are invalid. No extra authoring language or command is added.

Validate occurrence identities, semantic bindings and ordered route traversals
before physical layout. Layout uses the declared graphic nodes and edges, not
the exploration graph: repeated source members, decorative segments and
editorial routes retain their distinct occurrence identities. Geometry-free
text explicitly names its owning node or edge; it is never relocated by
guessing its meaning. Declared groups retain their membership.

The Archify adapter uses the [measured-text contract](#reader-notes-and-measured-node-text)
and existing font/Raster owner for complete text and icon footprints. ELK supplies
placement; native Archify owns routing and SVG assembly. Publisher qualifies the
complete frame, physical contacts, traversal continuity and actual paint clearance.
Resolved geometry stays private; literal composition retains its supplied geometry.

Node allocation and final paint share measured rows: font envelopes own leading,
while terminal ink and glyph bounds own the perimeter. Apply the inset once;
preserve row clearance and field separation without adding a terminal line box. Before any
route search, validate the fixed node and group paint without relationships.
A text or containment failure rejects that placement with its original subject;
changing ports or searching routes cannot repair it. Routing then qualifies
the complete relationship paint against those unchanged allocations.

#### Topology-first reading regions

Repeated geometry trials exposed a missing composition decision: exterior empty
space can coexist with congested central captions even when every rectangle is
valid. Select a graph-proved reading structure before native geometry. Existing
fork/join branches retain their qualified corresponding bands. A horizontal
pipeline trial failed the complete route-label pair gate; its implementation is
withdrawn, and that failed evidence does not qualify a new orientation.
A directed circuit with one actual
cross-cutting hub may use a surrounding circuit and an interior core when its
measured capacity fits. Direction, membership and every contributing edge remain
unchanged; this arrangement does not assert execution, causality or source hierarchy.

The existing topology owner derives the circuit and hub from exact endpoints,
with stable content-based ties rather than declaration order, product names or
relationship wording. Private native layout regions reserve complete caption,
endpoint and selected-stroke capacity on both axes. Native packing arranges these
regions; the existing native router handles all original relationships together.
Regions are not visible groups, additional entities or editable coordinates.
An unproved topology retains the general native alternatives; a failed frame is
not repaired by inventing this structure or excluding an inconvenient edge.

One complete renamed and permuted fixture and the complete self Overview and
Composition decide this approach. Full-frame proportions, captions, routes,
Legend and desktop chrome need actual visual review in addition to the same
semantic and paint gates. A new arrangement is not accepted merely because its
bounding box is smaller. This trial adds no source requirement, vendor change,
quality class or public tuning surface.

The internal desktop budget is derived from the actual 1440-pixel acceptance
viewport and native horizontal chrome, not the legacy 930-pixel fallback or an
unverified wide-screen assumption. The same measured budget feeds placement,
source typography, native reader fitting and its output check. Native layered
placement preserves declared hierarchy; ungrouped content also admits native
rectangle packing followed by native routing and measured label placement.
Rectangle placement never pretends to contain supplier-generated edge routes.
Pack measured node footprints inside private endpoint-escape envelopes on both
axes, derived from the existing endpoint, segment and selected-stroke clearances.
The ELK content target excludes outer padding; label width never expands every
node or increases the desktop budget. Remove the envelopes by translating the
exact node and label geometry, not by resizing painted nodes.

Automatic ports, routes and each complete nearby relationship label form one
tentative geometric candidate. Reuse native port spreading, routing and label
placement; keep accepted routes and labels reserved while the tentative own
label remains movable. Reconsider automatic sides before refusing, and preserve
explicit shared contacts. Freeze only after endpoint fidelity, actual-ink,
arrow, rhythm and independent-corridor checks pass. Revalidate the complete
scene before ranking; neither supplier internals nor their pinned bytes change.

Candidates retain every occurrence and assess the measured complete frame,
including fonts and Legend, by the actual desktop aperture, proportional envelope and route detour.
Placement and scoring share the aperture aspect; the legacy aspect applies only without an aperture.
Continuous complete-frame expansion distinguishes overfull alternatives before reading cost.
Card padding is not content: subtracting it rewards inflation. Each exact field's ink travel includes
horizontal and vertical line returns; relative excess is compared with its shortest feasible rendition.
The maximum per-field penalty scales frame cost so descriptions cannot mask fractured short titles.
No field weight, fictitious height or hard title minimum impedes complete large graphs.

Eligible acyclic flows try native multi-edge wrapping. Two packing slots compare
native aspect and width-bounded frames. Ordered flows use aspect-driven selection
and preserve topological reading order before geometric cost. Captioned networks
retain stable source order and a measured escape envelope in their aspect option;
uncaptioned networks retain bounded alternatives without spending empty caption
capacity. Disconnected peers keep width-bounded rows. Compact packing omits
private node escape envelopes, not the graph's endpoint-escape perimeter, paint or clearance predicates.
Exterior padding derives from existing endpoint, stroke and text clearances, not an arbitrary gap;
the router needs this workspace to reserve complete routes and nearby labels.
Every alternative passes the same route and ink audits.
The producer and worker share 64 pages with at most 12 candidates per page, within existing byte, memory and time limits.
Shared contacts remain exact; literal geometry does not enter this strategy.

Compact widths are preferences, not permission to fracture fitting words. The font owner derives each peer's minimum width from
its longest indivisible token plus the shared type-glyph rail and clearance.
Every candidate retains the same bounded width limit; only a token exceeding
that limit uses the existing exact grapheme-safe fallback. Fixed supplied
geometry retains its existing text composition.

Each sizing alternative must pass the final literal-paint validator. A failure
rejects that alternative, not an already validated complete candidate; the
finite search continues without weakening the validator or source semantics.

Evaluate identical complete geometry once; retain all distinct alternatives.
Reject envelopes exceeding the reading floor before routing; routes cannot
narrow nodes. Grid search first uses readable segments, then selected-stroke
resolution for exact escape corridors. Both passes preserve obstacles,
endpoints, paint, rhythm and label gates without changing vendor bytes or input.

Automatic composition refuses only after internal layout has been attempted.
It cannot clip, abbreviate, omit content, shrink below the readability floor,
invent grouping or require source coordinates or repository changes for fit.

An ordinary node's concise `note` passes unchanged to the native `tag` for
Passport, search and detail metadata. Its paint follows the measured-text
contract below, without a duplicate layer or collision waiver. Notes add no
assertions; conditional statements require attributed carriers and exact routes.

An authored scene may declare `typography.minimumTextPx` (6–32 CSS pixels) for desktop reading.
The private adapter derives source sizes from the shared desktop width and height aperture.
Its measured multiline allocation feeds fonts, baselines, validation, label masks,
glyph rails and Legend. Automatic scenes and literal scenes declaring a text floor
use the supported native intrinsic-height frame; undeclared literal scenes retain
authored-height and native single-line fitting.
Source-space font sizes remain separate from projected CSS-pixel reading targets;
the native primary target must not reuse an enlarged source-space font size.
The shell honors that contract; one canonical `data-legend` group also carries native type exploration.
Native chrome owns dock translation and reserve; the host budgets its toolbar without overriding lift.
Tall declared scenes still require actual paint, Legend and dock-clearance acceptance.
Resting-position metrics alone do not prove clearance. The removed translation override is
not a qualified adapter; another controller, hidden controls or a weaker floor cannot repair it.
Literal geometry and semantic membership remain unchanged; insufficient room refuses rendering.
Undeclared literal scenes keep incumbent presentation. This is a generic media requirement,
not an ETHOS quality contract or an independent layout authority.

One checked derivation owns source membership and query availability.
Paint IDs identify geometry; Inspect IDs identify selected source or Edition
occurrences; native node IDs index those occurrences. Derived capabilities,
not focusability or paint IDs, authorize queries and semantic coverage.
Complete declared coverage and exact bindings are not a carrier-source
bijection: aggregates bind multiple members, occurrences may repeat members,
and shared strokes retain distinct relations with exact endpoints.
The bridge normalizes native carriers without changing their attributes,
children or meaning, and creates no parallel semantic table.

### Reader notes and measured node text

Authored interactive scenes may provide `notes`: ordered cards with stable
`id`, `title` and `items`. Each item has `id`, exact plain `text` and
`semanticIds`; an empty binding set is explanatory text, never evidence.
Card and item identities share the page's graphic namespace. Notes reuse
Archify's native escaped cards; the adapter owns their neutral decorative dot.
They neither add graph vertices nor replace the complete diagram or required
directed routes. Titles do not witness Claims.

Bound items enter the existing statement-witness, coverage, facts, namespace
and Inspect owners. Every direct source or editorial statement still needs an
individually bound visible witness. Inspect retains the selected source digest
or Edition digest and exact attribution, without an embedded source copy.
Keyboard inspection restores focus to that same item. No raw HTML, arbitrary
style, executable note or separate claim table is admitted.

Ordinary labels, details and notes use one private measured multiline layout
at a declared desktop text floor; undeclared literal scenes retain native
single-line paint. The verified font/Raster owner supplies candidate widths and
final shaped ink bounds. Candidate widths do not prove fit. Paint, clearance
and refusal consume the same rows, while Passport, Finder and accessibility
metadata retain the unchanged original field strings.
Native fields consume the authored medium default's required normal 400 and
600 faces through the existing font resolver; no missing selected face falls
back to the bundled family. Text-only pages consume only their actual weights.
The declared floor is a constraint, not a suggestion. Automatic composition
derives boxes from all fields; explicit literal boxes that cannot contain them
fail before delivery. Moving explanations into notes is an editorial choice,
not an internal-layout repair. Every declared desktop figure uses the one
measured aperture; no legacy-width rule changes its floor or target.

Native presentation and SVG/raster exports show the complete diagram, not the
HTML notes hidden by those native modes. The reader explains that scope when
notes exist; full prose coverage is claimed only for ordinary HTML reading.
Static composition and acceptance remain independent.

### Node type encoding

The [Edition figure-type contract](../../../docs/edition-contract.md#figure-types)
owns one publication-wide resolved kind, label and glyph mapping. The Archify
[schema](https://github.com/tt-a1i/archify/blob/2ab3cae7ac2c2a55d7386ca789d03c4fcd31816c/archify/schemas/common.schema.json)
and [runtime contract](https://github.com/tt-a1i/archify/blob/2ab3cae7ac2c2a55d7386ca789d03c4fcd31816c/archify/references/viewer-runtime.md)
define native roles, not source taxonomy. `visualRole` selects paint only;
neither a glyph nor its color reclassifies a source entity.

`figureKind` selects an editorial architecture role. Homogeneous membership may
use its checked source kind; mixed membership needs an explicit figure role,
not an inferred `aggregate` type. Inspect retains exact member kinds and nulls.
The normal compiler derives the resolved encoding from declared kinds and its
checked glyph library. An editor may supply `visualPolicy.figureTypes` to
override it. Current mandatory catalog validation must converge at that owner,
not through a wrapper or source change. Capacity and ambiguous encodings fail
precisely; defaults never collapse kinds or invent a domain classification.

Resolve all selected pages before rendering. Equal kinds use equal artwork;
different kinds use distinct artwork and unambiguous reader labels. Nodes,
static keys, Legend, Passport, Lens and Finder reuse this exact resolution.
No per-occurrence overrides, copied reader or vendor patch is introduced.
Derived scene icons require no authored synchronization; literal refinement and
source-owned primitives retain their explicit choices.

Reuse the pinned offline Lucide library and complete notices through the
existing glyph/supply owners, without network loaders or handwritten artwork.
The locked build-only `lucide-static` subset retains complete ISC/Feather MIT
notices and supply hashes. The 2026-10-05 lookup covered historical 1.52.0 only,
not current safety. Normalize 24-unit artwork to the native 16-unit rail and
measure transformed footprints.

Native Legend resolution, collision checks and Lens own interaction. Each entry
places one glyph before its label, without count badges; membership remains
available to Lens. Pointer and keyboard share its native toggle. The existing
viewport owner reserves measured Legend/control space; sources do not repair
these bands. Literal/static bounds stay strict. Insufficient space is a
diagnostic, not permission to hide the Legend or shrink text. Hit bounds use
transformed entry coordinates. One native wording carrier serves localization
and runtime messages; authored relations do not become runtime traffic.

Export belongs to the selected native interaction, not an outside dismissal.
Original members and selected-source reading use native Route/Reach exports;
historical LikeC4 view export proves no parity. Canonical output removes
temporary reading state without a parallel export mechanism.

For original Archify-backed members, a native reading link combines the
publication URL, selected page and opaque native query hash. The bridge seeds
the hash before native startup; Archify retains parsing and selection. Same-page
address changes and browser history replace a completely prepared frame when
needed, without granting autoplay or retaining deferred predecessor work.
Page and opaque hash remain the rebuild identity; initial addressing replaces
the child history entry. Back, Forward, reload and cross-document return use
the native parser. Parent/member messages check the exact sender and page.

Historical LikeC4 addresses remain in their exact original artifacts and
receipts. Current Archify navigation does not reinterpret them or claim a live
compatibility reader. Accepted predecessor custody and current addressed-reading
qualification remain separate.
