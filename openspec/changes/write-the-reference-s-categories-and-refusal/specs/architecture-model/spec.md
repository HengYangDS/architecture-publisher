## ADDED Requirements

### Requirement: The model reference written from the model's statement

The model reference's table of categories, each with its default icon and how it is drawn, and its rule of a status
SHALL be written by a command from the model's schema and the categories' registry. The command line reference's
sample refusal SHALL be written by the same command from the publisher's own output on a committed sample model.

#### Scenario: A reference that differs from its sources

- **WHEN** the model reference's table of categories or rule of a status, or the command line reference's sample
  refusal, differs from what the command writes
- **THEN** the check of generated inputs fails and names the document
