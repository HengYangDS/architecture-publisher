# Proposal

## Why

The current ETHOS migration packet can be read as if a passing Edition Provider
and `archpub edition build` reproduce the already reviewed flagship static image
and interactive Atlas. Current source does not support that inference: the
Provider delivers standard values, while the generic compiler does not consume
ETHOS's authored media composition. An operations reference also omits the
currently exported ETHOS Provider entrypoint.

## What Changes

- Clarify the Provider's exact semantic and structural output boundary.
- Separate ETHOS Provider conformance from source-owned flagship Edition
  composition and exact media acceptance, following the existing self-Edition
  pattern without adding a command plane.
- Correct the current ETHOS package export list and label migration incumbents.

## Capabilities

### New Capabilities

None.

### Modified Capabilities

None. This corrects documentation and handoff criteria, not product behavior.

## Impact

Only the canonical Provider reference, ETHOS migration packet, operations
reference, and this Change are affected. Public APIs, packages, specifications,
release assets, and historical signed tags remain unchanged.
