## ADDED Requirements

### Requirement: The palettes' table in the model reference

The model reference's table of the built-in palettes, each with its names and its colours and the default marked,
SHALL be written by a command from the house's palettes and the model's schema.

#### Scenario: A palettes table that differs from the house

- **WHEN** the model reference's table of palettes differs from what the command writes
- **THEN** the check of generated inputs fails and names the document
