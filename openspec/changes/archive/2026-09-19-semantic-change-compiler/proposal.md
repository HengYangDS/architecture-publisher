## Why

The publisher compares ETHOS values but has no portable semantic change contract.
Direct view membership misses transitive dependencies, while identity changes and
unknown dependencies need explicit treatment rather than optimistic reuse.

## What Changes

- Add a bounded semantic document and deterministic change compiler with explicit
  source-backed rename, split and merge correspondence.
- Compile conservative dependency impact into distinct rebuild, verification and
  review obligations; never mint acceptance or infer natural-language equivalence.
- Replace the ETHOS-specific comparison algorithm with an adapter to this owner.
- Expose digest-selected comparison through the installed offline CLI.
- Preserve the accepted artwork and qualify the compiler independently.

## Capabilities

### New Capabilities

- `semantic-compilation`: portable source-backed semantics, change and impact.

### Modified Capabilities

None. Existing candidate support remains bounded; its comparison implementation
uses the new owner without advertising arbitrary candidate rendering.

## Impact

Only semantic modules, the ETHOS adapter, CLI, tests, package metadata and existing
product documentation change. No runtime dependency is added. No ETHOS source,
accepted artwork, Documents file, previous release or predecessor repository is
modified. A second adopter, automatic composition, editor, graph database, live
sync and marketplace remain outside this increment.
