# Proposal

## Why

The tracked Superpowers implementation plan still presents every step as
unchecked after the Edition Provider Change was archived and released. Its
checkboxes are a second, contradictory progress ledger alongside the canonical
OpenSpec `tasks.md`. No current product document or test references that plan.

## What Changes

- Remove the superseded plan from the current tree. Git history retains its
  exact bytes and the archived OpenSpec Change retains the implementation
  decisions and completed task ledger.
- Leave the product contract, active specifications, runtime, tests, release
  assets, and signed historical refs unchanged.

Change are affected. No implementation or package input changes.
