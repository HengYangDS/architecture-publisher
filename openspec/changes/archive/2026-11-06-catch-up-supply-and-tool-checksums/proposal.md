## Why

Measured on 6 November at a cutoff 24 hours back, the development supply has
three gaps and one leftover:

- npm 12.2.2 has been public for a day. It fixes a race in npm's cleanup of its
  working directory and accepts supported Node.js prereleases, and it updates
  the undici and ip-address it bundles. While the repository pins 12.2.1, a
  workstation whose own mise configuration declares 12.2.2 finds that npm first
  and refuses the repository's commands with `EBADDEVENGINES`.
- `@napi-rs/wasm-runtime` 1.2.7 is the one entry of the lock behind the newest
  release its range allows.
- The mise lock names the archives of `github:tamasfe/taplo` 0.10.0 by URL
  without a checksum. mise 2026.11.2, which the workstation moves to next,
  refuses such an entry in its safe and locked modes, so `mise install` stops
  before it installs any tool.
- `.config/mise/locks/mise.ci/` still holds a lock of npm 12.2.0. It belonged to
  the CI configuration that `.config/mise/config.toml` replaced on 22 October,
  and no configuration reads it.

## What Changes

- npm 12.2.2 in `devEngines`, `packageManager` and the mise declaration.
- The mise lock regenerated by the pinned mise: npm 12.2.2 with the lock of
  npm's own package, a checksum for each of Taplo's archives, and pixi's entries
  only for Linux, the one platform the configuration installs it on.
- The orphaned npm 12.2.0 lock removed.
- `@napi-rs/wasm-runtime` 1.2.7 in the npm lock.

## Capabilities

## Impact

`package.json`, `package-lock.json`, `.config/mise/config.toml`, the mise lock and
the locks of npm's package, and the changelog. The published package declares no
dependency, and what a build delivers does not change.
