# Proposal

## Why

The archived Provider design assigns all Scene compilation and rendering to
Architecture Publisher, while the released self-Edition actually owns its
flagship compositions. The current product contract has an abstract owner table
rather than one cross-product Authority Matrix, and it does not make release
custody distinct from generated-file location. This can misdirect ETHOS slimming
or AIGW artifact adoption.

## What Changes

- Replace the existing owner table in the canonical product contract with one
  current Authority Matrix applying to Publisher self, ETHOS, and AIGW.
- Separate source meaning and bespoke media authorship from generic Publisher
  compilation, verifier evidence, source-product acceptance, and selected
  artifact custody.
- Clarify that archived matrices are historical and that a release asset is an
  output subject, not automatically source-repository content.

## Capabilities

### New Capabilities

None.

### Modified Capabilities

None. This is a documentation correction, not a behavior or schema change.

## Impact

Only `docs/product-contract.md` and this Change are affected. Historical
proposals, packages, public APIs, releases, and signed tags remain unchanged.
