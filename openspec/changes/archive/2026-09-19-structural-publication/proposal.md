## Why

The product can compare structured meaning and can render authored diagrams, but
it cannot yet turn one source-bound semantic graph into a complete static
overview plus complete interactive mechanism views. ETHOS candidate preparation
therefore rejects real entity or relation membership changes, and the existing
non-ETHOS examples are authored fixtures rather than a source-bound adopter
journey.

## What Changes

- Add one generic, bounded semantic-publication compiler for architecture graphs.
- Bind every semantic source to exact bytes in a selected source bundle.
- Require authored grouping and within-group order for every visible entity, and
  explicit endpoint sides and route style for every visible relation.
- Produce one complete overview SVG and one complete HTML diagram per declared
  view, plus a manifest that records source, authoring and artifact identities.
- Demonstrate the addition of AIGW's ordered client registry and its relations
  from exact historical repository bytes, then replay both revisions from an
  installed package in a relocated offline directory.
- Reject omissions, contradictions, stale identities, unsupported styles and
  renderer-declared geometric infeasibility before publication succeeds.

## Capabilities

### New Capabilities

- `semantic-publication`: source-bound structural publication across static and
  interactive media for a finite architecture vocabulary.

### Modified Capabilities

None.

## Impact

This is the selected P1 structural-evolution family and the P2 AIGW adopter
journey. It does not change ETHOS product meaning, infer architecture from code,
claim arbitrary-domain layout, or create a graph database, editor or service.
The generic compiler contains no AIGW or ETHOS branch; adopter meaning remains
in explicit portable inputs.
