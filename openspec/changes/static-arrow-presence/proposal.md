## Why

The static audit rejects valid unarrowed junction segments by applying arrow
terminal length and envelope checks whenever parameters exist. The literal
contract carries arrow parameters even when its arrow is false; presence is not
paint. Thirty-six selected ETHOS bridges fail this incorrect predicate.

## What Changes

- Use actual arrow presence in the existing static audit and canvas-envelope owner.
- Retain historical absent-flag default arrows, shaft geometry, attachment and glyph clearance.
- Preserve schemas, command surfaces, source relations, frozen releases and independent media.

## Capabilities

### New Capabilities

None.

### Modified Capabilities

- `flagship-qualification`: static directional checks follow declared arrow presence.

## Impact

Only the existing static audit, regression tests and successor release identity
change. ETHOS-specific glyphs and acceptance remain source-owned. No renderer
fork, new rule store, dependency, mobile view or compatibility alias is added.
