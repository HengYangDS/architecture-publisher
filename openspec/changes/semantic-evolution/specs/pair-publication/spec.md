## ADDED Requirements

### Requirement: New-edition evidence applicability

Qualified publication SHALL bind new source, authoring, output and fresh scoped
review and browser observations; previous-edition acceptance SHALL NOT qualify
new bytes by inheritance.

#### Scenario: Newly generated edition is selected

- **WHEN** a new semantic candidate is selected for publication
- **THEN** semantic, visual and browser observations cover the selected new identities
- **AND** publication delegates its exact file replacement to the existing installer

#### Scenario: Old browser observation is supplied

- **WHEN** observation subjects do not match the selected new output
- **THEN** qualification rejects publication without modifying destinations
