Use the existing semantic compiler, candidate preparer, complete atlas renderer,

## Mechanism choices

Primary documentation inspected on 2026-09-19:
- Penrose Style: https://penrose.cs.cmu.edu/docs/ref/style/overview
  Separate domain meaning, instance facts and visual rules. Adopt this boundary,
  not its optimizer or a new language for one fixed edition.
- ELK Layered: https://eclipse.dev/elk/reference/algorithms/org-eclipse-elk-layered.html
  Explicit ports, label spacing and compound graphs make routing constraints
  concrete. Retain existing exact geometry gates; defer solver integration until
  a real topology change exceeds this composition's capacity.
- Bazel Skyframe: https://bazel.build/reference/skyframe
  Correct invalidation depends on complete recorded inputs. Keep unknown semantic
  dependencies conservative and distinguish rebuild from review; no cache based
  only on graph counts or provenance hashes.
- Structurizr DSL: https://docs.structurizr.com/dsl
  A shared model supplies multiple selected views. Preserve common semantic
  identities while letting static and interactive layouts differ.

Documentation establishes mechanism contracts, not comparative code quality,
performance or proof that these tools meet this product's aesthetic requirements.

## Chosen implementation

Replace the node-specific candidate schema with a bounded authored-edit schema.
Each edit identifies an existing page and explicit component/card text site,
expected prior text and replacement text. Source bindings carry kind, identity,
complete-value digest and selected visible carriers. Page order is explicit and
must be a permutation of the complete previous catalog; neither accidental page
loss nor arbitrary JSON patch paths are permitted.

Reject edits to source meaning, unrecognized sites, duplicate sites, stale
preimages and unsupported topology. All changed node/relation/assertion values
must have explicit source-bound visible carriers. Contract/presentation changes
without a supported mapping remain rejected. Hash binding detects staleness; it
does not prove prose equivalence, which remains an explicit review obligation.

Static editing uses the same existing label construction and actual metrics,
with source-bound carrier records. The same semantic and geometry gates run on
composed and emitted geometry. Long text is rejected as infeasible rather than
silently shrunk or omitted. No generated SVG or HTML is hand-edited.

Existing refresh content becomes an authored input to this one preparation
contract, not a compatibility implementation. Preserve historical accepted
rendering inputs and bytes. Candidate-only changes cannot weaken replay locks.
