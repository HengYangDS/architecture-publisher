# Architecture Publisher documentation

New to the publisher? Start with the tutorial. For a task you already know, use
the how-to guides; for every detail, the references.

- [Tutorial](tutorial.md): publish a first work, step by step.
- [How-to guides](how-to.md): install, import, write a guide, state an overview, re-pin and hand a work to a reviewer.
- [Glossary](glossary.md): the words the publisher uses.
- [Product contract](product-contract.md): what the product does, its inputs, outputs and quality floor, and the queue it is built in.
- [Roadmap details](roadmap.md): what each item of the queue does, and the protocols it runs by.
- [Research](research/README.md): the studies, measurements and records that decisions rest on, one page each.
- [Model reference](reference/model.md): every field of an Architecture Model.
- [Line values](reference/lines.md): the weights and patterns of a plate's lines, and what each means.
- [Data and reader file reference](reference/data.md): the model, the data and the reader file of a delivery, the evidence table and a plate's face.
- [Operations reference](reference/operations.md): commands, layout and the delivery.
- [Refusals reference](reference/refusals.md): every code a check or a build refuses with.
- [Command line reference](reference/command-line.md): help, exit statuses, JSON results, reports and progress.
- [Development and reference](reference/README.md): toolchain, configuration and verification.
