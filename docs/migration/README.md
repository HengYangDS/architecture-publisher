# Source independence

Source repositories supply existing material read-only. Their external editors
own publication inputs and artwork. Each reference separates observed source
removal from unfinished publication acceptance.

- [AIGW external publication](aigw-edition-provider.md): Client scope, preserved inputs and source safety.
- [ETHOS external publication](edition-provider-ethos.md): source removal, external responsibility and retained meaning.
