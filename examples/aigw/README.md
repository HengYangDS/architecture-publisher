# AIGW semantic publication

This is one real non-ETHOS adopter of the generic semantic publication contract.
It records an actual AIGW structural change: the ordered operational client
registry introduced at commit `069c2a655a5a1b9124d656e64b2d323ff53baf11`
over parent `36a6a28336280b71c4dc8d793a75bdb2671bb73c`.

The `initial/` and `evolved/` directories contain reviewable semantic and
medium-specific authored inputs plus exact selected source bytes. Build scripts
create source manifests, plans, standalone HTML pages and independently composed
SVG/PNG output under ignored evidence or artifact directories; generated
identities do not live beside these inputs.

The model is curated from exact source. It does not claim automatic code
understanding, AIGW product approval or complete representation of every package.
It is the independent non-ETHOS adopter; `examples/self-host/` is complementary
self-use evidence and does not replace this boundary.
