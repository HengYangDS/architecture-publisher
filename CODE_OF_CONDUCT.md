# Code of conduct

This project adopts the
[Contributor Covenant, version 3.0](https://www.contributor-covenant.org/version/3/0/code_of_conduct/).
It holds in issues, pull requests and anywhere the project is discussed.

In short: be kind and assume good faith; discuss the work, not the person; no
harassment, insults or unwelcome attention.

Report a problem privately to the maintainer, at the email address on
[their GitHub profile](https://github.com/HengYangDS). The maintainer reads
every report, keeps the reporter's name to themself, and may remove comments
and block people who do not keep to the code.
